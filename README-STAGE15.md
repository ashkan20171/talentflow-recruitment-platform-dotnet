# Stage 15 — Candidate Experience & Smart Workflow

This stage extends the .NET Framework 4.8 recruitment suite with a role-focused candidate workspace.

## Added
- Candidate home dashboard with live open-job, saved-job and alert KPIs
- Saved jobs shortlist backed by the existing Favorites table
- Job Alerts with keyword, city and daily/weekly frequency
- Application Timeline view
- Candidate-only navigation entries and role-aware workspace
- Audit events for saved jobs and alerts
- Incremental JobAlerts database migration
- Additional indexes for Favorites and JobAlerts

All previous Stage 14 responsive shell, RTL/LTR behavior, permissions, recruitment operations, security and reporting modules are retained.
