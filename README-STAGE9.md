# Ashkan Job Center — Stage 9 Production Polish

.NET Framework 4.8 WinForms recruitment management suite.

Stage 9 adds Advanced Search, operational Reports with UTF-8 CSV export, Feature Flags administration, Session Security view, database indexes, audit events, and tighter permission-aware navigation.

## Run
Open `AshkanJobCenter.sln` in Visual Studio 2022, restore/build, then run. SQL Server LocalDB is required.

Default administrator: `admin` / `Admin@123` (change for real deployments).
